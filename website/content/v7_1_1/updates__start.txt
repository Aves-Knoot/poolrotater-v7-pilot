====== Release history ======

Player-facing patch summaries, newest first. Compatible updates are cumulative, but owner and independent-host packages can follow different supported baselines. Publishing a download, queuing an update and observing it installed are separate events.

===== Current rollout =====
**Reviewed October 15/16, 2026 Pacific time:** The owner's three configured rooms—fixed Standard, Mania 4K and Mania 7K—are running **[[updates:v7_0_7|v7.0.7]]**. Automatic Standard remains intentionally disabled; three owner rooms is the expected topology.

**[[updates:v7_1_1|v7.1.1]] is the latest published successor**, with default-on sharing, explicit opt-outs, signed automatic delivery and network-wide occupancy totals. It supports the exact v7.1.0 baseline. Existing v7.0.6/7/8 hosts first use the supported one-time [[updates:v7_1_0|v7.1.0 stopped storage migration]]; the automatic feed does not cross that storage boundary. New defaults preserve explicit operator choices.

The hub, private statistics publisher and existing statistics website are upgraded. The owner’s first v7.1.0 migration is queued for a natural all-three-empty window; publication of v7.1.1 does not mean those rooms have already migrated. Other hosts’ installed versions must be confirmed from their own diagnostics.

[[updates:v7_0|v7]] retains the familiar gameplay while adding independently operated lobbies, complete centrally prepared signed catalogs and optional directory/feedback sharing. Compatible worker-only updates can wait room by room; a shared-controller change needs coordinated empty-room maintenance. [[wiki:room_updates|Update behavior]] explains the admission and recovery checks. [[status:start|Live Lobbies]] supplies fresh observations; the version statements here are dated review facts.

===== Public source and downloads =====
[[https://github.com/Aves-Knoot/poolrotater-v7-pilot|The GitHub repository and existing release downloads are now public]]. Full published history and all 47 release assets were audited for sensitive information before the change. No live credentials, private signing keys, private contact details or player-history tables were found. Public handles and dependency attribution remain. Secret scanning and push protection are enabled. This visibility/documentation change preserves runtime bytes, existing checksums, settings and running rooms; it does not assign a new bot version or enable automatic installation.
