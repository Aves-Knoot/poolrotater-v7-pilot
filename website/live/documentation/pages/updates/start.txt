====== Release history ======

===== Live rollout checkpoint — October 25 =====

v7.3.3 is running on the owner host and both community hosts. The owner now runs Catch on Lobby 1, a Taiko automatic-difficulty pilot on Lobby 3, and Mania 4K on Lobby 4. Lobby 2 remains reserved/private and stopped. Existing settings were preserved; the owner intentionally changed only Lobby 3's mode and activated the new signed catalog bindings. Current links and settings are on [[status:start|Live Lobbies]].

The Taiko pilot's startup, chat access, map selection, queue, website artwork/settings and Discord panel are verified. Actual Taiko player gameplay has not yet been observed. Its NoMod normal-speed catalog and the latest Standard catalog are activated.

One community host's Standard transfer stopped at about 94%. Its configuration remained unchanged, but its independently pinned v7.2.6 recovery reader could not dispatch the newer controller contract. Completion through the already-installed v7.3.3 native entry resumed the verified partial download and restored its two intended rooms. Reporting, ratings and updater status are healthy. Bounded transfer retries and recovery-pin refresh are being validated for a follow-up release; those new changes are not yet published. The separate earlier pre-admission interruption test remains a documented limitation.

Player-facing changes, newest first. Published releases and the version running in a lobby can differ during a rollout; check [[status:start|Live Lobbies]] for current rooms.

===== Current rollout =====

**Latest published: [[updates:v7_3_3|v7.3.3]].** Taiko fixed/automatic rooms, ruleset-separated ratings and statistics, prepared Taiko selection data, and verified shared-rating synchronization. The GitHub release is published; the signed pilot feed now offers it to supported existing hosts at safe update boundaries.

Shared-controller updates wait until all configured rooms on each host are empty. Compatible worker-only updates can roll one empty room at a time. Publication does not force a restart, remove players, or start a deliberately stopped host.

===== v7.3.3 release =====

**v7.3.3 is published on GitHub.** Its normal installed paths passed on v7.3.0 H and v7.3.2 I (2 of 2). A separate extra B pre-admission controller-interruption case failed before incoming code could run and remains unaccepted; it is documented as a limitation. The signed pilot feed now offers the release to supported existing hosts; safe automatic rollout is underway.

This release includes fixed/automatic Taiko presets using qualified normal-speed NoMod difficulty; separate Taiko rating/statistics identity; bounded ratings retries and verified shared-count replies; and a full prepared Taiko catalog. The selected catalog contains 37,635 Ranked/Approved charts (37,447 native and 188 officially qualified conversions); player research tables are not shipped. H and I receipts confirm the Taiko and latest full Standard catalog references on both normal installed paths.

Controller updates preserve occupied rooms and deliberately stopped slots. Empty siblings may drain one at a time, while controller installation waits until every configured room is empty and active bookings are clear. This behavior and settings preservation passed on both normal paths; the separate extra B pre-admission controller-interruption case failed and remains unaccepted. The hub, community Discord bridge and website deployments are verified. The Discord connection is live; no owner Lobby 3 Taiko pilot or actual Taiko gameplay is claimed. Signed-feed delivery is active; downloaded or queued does not yet mean installed.
