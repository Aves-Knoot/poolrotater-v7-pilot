# Actual room activation is a later pilot

Dev27 provides verified database downloads from the owner VPS. It does not
authorize an account, install a room service or host rooms. Keep using a fresh
ordinary-user download installation; do not migrate the old rehearsal receipt.

Next development: supported protected installation, separate execution/client/
OAuth/pacing/ownership/catalog bindings and installed authorization/service entry
(LA2), followed by integrated invented-provider donor acceptance (LA3). Only
after that qualification should the consenting operator authorize their own
account locally for one observed room. No credentials/codes should be sent to
the maintainer or embedded in the repository. Shared ratings and directory
enrollment are later workstreams.
