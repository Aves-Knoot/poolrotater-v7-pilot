# Managed automatic updates

Signed automatic updates are part of managed participation. Discovery, verified
download, queued, waiting-empty, installed and healthy are distinct states.
Compatible worker updates can replace one empty room at a time. This managed
controller release uses the host-wide safe gate. Occupied siblings are retained
until that gate is met. Explicitly stopped rooms stay stopped; all-off hosts need
positive clean ownership, not temporary rooms created just to permit an update.

Retain journals, receipts and reports after an uncertain or interrupted update.
The exact staged successor prepares policy/data/configuration under the stopped
owner lease. It retains saved ceilings, account authorization, Discord settings,
catalog IDs, ratings and history. An older unsupported host stays operational
and reports missing capabilities; it is not silently treated as administered.
Never use an old one-time repair helper as a general upgrade command.
