# Standard Auto + Mania 4K operator test

Install using TWO_ROOM_OPERATOR_HANDOFF.md. For an existing same-topology pilot,
upgrade it stopped using OWNER_HUB_UPGRADE.md; adding a second room requires the
documented fresh `two` route and does not migrate old preferences/votes.

1. Record release/runtime digest, OS, time/timezone and before-support. Confirm
   full Standard/4K/7K catalogs, expected account, clean ownership and stopped old
   installation. Use room-settings-status to verify Standard room1 and4K room2
   public titles and saved defaults. No manual overlay or journal edits.
2. Start once, run active status/support and room-settings-status, and return both
   room links. If uncertain, preserve state and return safe stage/code/HTTP status
   before retrying. The hosting account remains a referee; other accounts play.
3. Play3–5 maps per room. Exercise help/queue, good/bad votes, skip, Standard
   easier/harder, countdowns, ready/unready/AFK with2players and normal joins/leaves.
   Report which checks were actually exercised per mode and real map IDs/times.
4. Send installation/generation UUIDs, hosting ID and separate directory/ratings
   consents for a bound invitation. Enroll only after maintainer approval. Central
   contribute permission must precede local sharing; no historical seed. Keep
   independent selection weighting for this first test.
5. Capture network-support/ratings-support. `progress.locally_captured_events`
   counts captured events, not distinct people or final opinions. Queued upload
   events are pending/retryable; accepted/already-accepted outcomes are central
   acknowledgments. An acknowledgment does not prove inclusion in aggregates.
   Nonaccepted outcomes require review, not repeated uploads or state deletion.
6. After the nominal30minute upload interval, inspect progress. A complete
   downloaded shared snapshot is separately verified. Its map count/watermark
   and configured reader eligibility do not prove the running workers adopted
   network weighting. Preserve local selection until explicit separate agreement.
7. If directory consent is enabled, check both public rooms in the website's
   Community Lobbies section and confirm the original four owner cards are
   separate. Private, revoked and expired rooms must not have fresh join links.
   Coordinate any outage test with the maintainer; do not stop other services.
8. When empty, stop once, then network-stop if it was started. Confirm actual
   upstream closure, no dedicated processes and clean stopped ownership. Capture
   after-support/review. Continuing a public pilot requires explicit agreement.

Return before/active/after safe support, links/times, completed checks, errors,
vote map IDs/times and counters, title/range correctness and usability notes.
Do not send secrets, tokens, invitations, callback URLs/codes, private pacing
hashes, player identities or unredacted logs. Binding IDs are sent separately
only for enrollment. Simulated donor acceptance does not replace human gameplay.
