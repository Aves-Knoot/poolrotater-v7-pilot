# Security reports and local secrets

Report a suspected vulnerability to the maintainer through an existing private
support channel. Share the affected version and a minimal, redacted reproduction.
Do not post OAuth codes or tokens, client secrets, Discord credentials, enrollment
invitations, host credentials, private signing keys or installed state in issues.

Public CA certificates, public verification keys, signed release metadata and
artifact checksums are deliberately distributed verification material. Their
private signing counterparts and every operator's credentials remain local.

The public repository contains reviewed source and installation downloads. It
does not include the owner's development workspace, operational logs, research
databases or player records. Dependency notices retain their original attribution.
Public visibility does not enroll a host or enable automatic installation.
